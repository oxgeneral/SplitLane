# Отдельный выход AmneziaVPN

Локальная сборка SplitWebOnMac умеет направлять HTTP/HTTPS-запросы группы в отдельное подключение AmneziaWG. Для запуска подключения из окна Amnezia нужен патч к исходникам AmneziaVPN 5.1.0.6.

## Локальная сборка

Открой `.build/amnezia-mode/AmneziaVPN for SplitWeb.app`. Если штатная Amnezia уже открыта, сначала выйди из неё. У тестовой копии есть доступ к тому же списку подключений. macOS может запросить разовое разрешение на чтение настроек. Изменения в тестовой копии действуют до её закрытия. Сборка загружает Qt и зависимости из папки проекта.

В тестовой копии нажми **Подключиться**. В SplitWeb создай группу с выходом **AmneziaVPN · отдельный выход**, добавь приложения и включи правила. При остановке Amnezia распознанные запросы группы прекращаются до переподключения.

## Упаковка для SplitWebOnMac

Передай собранное приложение с применённым патчем, помощник AmneziaWG, каталог Qt 6.10.1 и каталог `client/ui/qml` из исходников Amnezia.

```sh
bash Integrations/Amnezia/package-macos.sh "$amnezia_app" "$awg_helper" "$qt_dir" "$qml_dir" "$output_app"
SPLITWEB_AMNEZIA_APP="$output_app" ./build.sh standalone
```

Патч находит `splitweb-awg` рядом с исполняемым файлом AmneziaVPN. В самостоятельной сборке обе программы и библиотеки Qt входят в комплект.
Для обновления профилей Premium патч использует публичный ключ и адреса шлюза из официального macOS-релиза 5.1.0.6, если они не заданы при сборке. Профили и ключи подключений остаются в настройках пользователя.

В экспериментальном режиме клиент передаёт параметры выбранного AmneziaWG-подключения дочернему процессу через закрытый канал. Дочерний процесс запускает AmneziaWG в памяти и публикует локальный выход для SplitWeb. Запросы к DNS идут через туннель к серверу из профиля. Остановка процесса закрывает этот выход, и SplitWeb блокирует запросы группы до переподключения. Системный выход и DNS обслуживаются macOS.

## Сборка компонента

Из корня проекта

```sh
(cd Integrations/Amnezia && go build -mod=readonly -tags 'with_awg,with_gvisor' -o ../../.build/splitweb-awg .)
```

Проверь два тестовых узла AmneziaWG с локальными DNS и HTTP

```sh
(cd Integrations/Amnezia && go test -mod=readonly -tags 'with_awg,with_gvisor' -timeout=25s .)
```

## Интеграция в клиент

Патч `amnezia-client-5.1.0.6.patch` применяется к чистым исходникам [AmneziaVPN 5.1.0.6](https://github.com/amnezia-vpn/amnezia-client/tree/5.1.0.6). Для сборки клиента нужны его Qt 6.10.1, зависимости Conan и окружение macOS из [рецепта сборки](https://github.com/amnezia-vpn/amnezia-client/blob/5.1.0.6/.github/workflows/deploy.yml).

В отдельной собранной копии режим включается переменной `SPLITWEB_AWG_HELPER` с абсолютным путём к проверенному `splitweb-awg`. Запусти исполняемый файл этой копии с переменной, выбери AmneziaWG-подключение и нажми **Подключиться**. В SplitWeb выбери **AmneziaVPN · отдельный выход**. Состояние «Локальный выход открыт» показывает, что процесс принимает запросы. Доступ к серверу проверяется фактическим запросом через группу.

Патч собран с Qt 6.10.1 и проверен с сохранённым AmneziaWG-подключением. Тестовые HTTP/HTTPS-запросы одновременно вышли через Amnezia в Нидерландах и через Happ в Швеции. После отключения Amnezia её запросы прекращались, а Happ и системный маршрут продолжали отвечать. Текущая версия охватывает один AmneziaWG-туннель и внешний адрес сервера IPv4. При смене физической сети подключись заново.
